PATHS AND PREVIEW
Both HTML pages use the relative stylesheet path css/style.css. Keep the css
folder beside index.html and detail.html. Open index.html in a browser or use
Live Server in VS Code. The Home and Case Study links connect the two pages.
The layout stacks on mobile and uses CSS Grid on desktop at 768px and wider.

FIGMA WIREFRAMES
Figma file: https://www.figma.com/design/QriOYPXr3qS1Suo0SY2vbh
It contains desktop and mobile frames for both pages, plus a Design Tokens
page with the blue palette, spacing, and card-radius variables.

DESIGN DIRECTION
The portfolio presents Yahya Faheem as a Digital Enterprise Management student
at UTM interested in the space between business, technology, and people. The
visual direction uses a bold blue hero, editorial typography, and distinct
project panels.
